# University AI Assistant

🤖 Интеллектуальный ассистент для работы с базой данных университета через естественный язык.

## 📋 Что это?

Веб-приложение, которое понимает вопросы на русском языке про университет, превращает их в SQL-запросы и даёт понятные ответы. Работает через YandexGPT и PostgreSQL.

## 🎯 Что умеет?

- **Понимать вопросы** на русском: "сколько студентов на лингвистическом факультете?"
- **Генерировать SQL** автоматически
- **Проверять безопасность** — только чтение, никаких изменений в базе
- **Исправлять ошибки** — если запрос не работает, система пытается его починить
- **Отвечать по-русски** — понятно и без технических деталей
- **Работать в браузере** — удобный чат-интерфейс
- **Работать в консоли** — для тех, кто любит командную строку

## 🚀 Как запустить?

### 1. Установите Python 3.8+ и PostgreSQL

### 2. Установите зависимости
```bash
pip install asyncpg requests
```

### 3. Получите ключи Yandex Cloud
- Зарегистрируйтесь в Yandex Cloud
- Создайте API-ключ для доступа к YandexGPT
- Запомните Folder ID

### 4. Настройте подключение к базе
Отредактируйте в коде переменные:
- `DB_HOST` — адрес сервера PostgreSQL
- `DB_NAME` — имя базы данных
- `DB_USER` — пользователь
- `DB_PASSWORD` — пароль

Или используйте переменные окружения.

### 5. Запустите
```bash
# Веб-версия (откроется в браузере)
python main.py

# Консольная версия
python main.py --console
```

Веб-версия будет доступна по адресу: `http://127.0.0.1:8000`

## 🔒 Безопасность

- Разрешены **только** SELECT-запросы
- Запрещены любые изменения данных (INSERT, UPDATE, DELETE и т.д.)
- Система проверяет каждую таблицу по белому списку
- Блокируются системные схемы PostgreSQL
- Личные данные студентов скрываются
- Автоматические таймауты на долгие запросы

## 🗄️ С чем работает?

Система знает структуру университета:
- Факультеты, кафедры, программы обучения
- Студенты, преподаватели, группы
- Оценки, расписание, абитуриенты
- Статистика поступления и успеваемости
- Специальные представления для быстрых запросов

## 📝 Примеры вопросов

Попробуйте спросить:

- "сколько студентов обучается на лингвистическом факультете?"
- "кто декан факультета Лингвистика?"
- "сколько всего студентов в университете?"
- "какие группы есть на факультете математики?"
- "сколько преподавателей работает на кафедре информатики?"

## 📊 Что сохраняется?

Все запросы логируются в таблицу `query_logs`:
- Текст вопроса
- Сгенерированный SQL
- Время выполнения
- Результат (успех/ошибка)

## 🛠️ Как это работает?

1. Вы задаёте вопрос по-русски
2. YandexGPT превращает вопрос в SQL-запрос
3. Система проверяет безопасность запроса
4. Запрос выполняется в PostgreSQL
5. Если ошибка — система пытается исправить запрос
6. Результат превращается в понятный ответ по-русски
7. Вы получаете ответ в чате

## 🔧 API для разработчиков

Если хотите использовать ассистента в своём приложении:

**Отправить вопрос:**
```
POST /api/ask
{"question": "текст вопроса"}
```

**Ответ:**
```json
{
  "ok": true,
  "answer": "понятный ответ на русском",
  "sql": "сгенерированный SQL-запрос",
  "row_count": 5,
  "response_time_ms": 245
}
```

**Проверить статус:**
```
GET /api/health
```

## 💡 Важные моменты

- Используйте **свой** API-ключ Yandex Cloud, не публикуйте его
- База данных должна быть доступна с сервера, где запущен ассистент
- Для сложных вопросов система может делать до 2 попыток исправления SQL
- При первом запуске может потребоваться ввести пароль PostgreSQL вручную

## 🤝 Помощь

Если что-то пошло не так:
- Проверьте, что PostgreSQL запущен и доступен
- Убедитесь, что API-ключ Yandex Cloud действителен
- Посмотрите логи в консоли — там обычно понятно написано, что не так
