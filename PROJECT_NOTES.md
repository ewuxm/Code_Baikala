# Подготовка репозитория

Этот пакет подготовлен для публикации проекта «Код Байкала AI» на GitHub.

Важно:
- `app.py` здесь очищен от обнаруженных в исходнике захардкоженных секретов;
- используйте `.env.example` как шаблон;
- реальный `.env` в GitHub не загружайте;
- если старые ключи уже где-либо публиковались, их нужно отозвать и заменить.
